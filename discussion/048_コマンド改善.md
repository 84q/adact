# CLI/MCP コマンド改善

## 背景・目的

CLI/MCP コマンドの使い勝手を改善する。不要なコマンドの削除と、既存コマンドの柔軟性向上。

## 変更一覧

### 1. clear 削除

- 削除対象: `adact_clear` MCP ツール + CLI `clear` サブコマンド
- 理由: `fill` で空文字列 `""` を指定すれば同等の操作が可能
- 影響: breaking change（AIエージェントが clear を使っている場合は fill に切り替え）

### 2. resize-window 片方指定対応

- 変更対象: `adact_resize_window` MCP ツール + CLI `resize-window` サブコマンド
- 変更内容: width / height のどちらか片方のみの指定を許可
- 動作: 指定がなかった方は現在のウィンドウサイズを取得し、そのまま維持
- 現状: 両方必須

### 3. scroll 拡張

#### 3a. 既存 scroll のリネーム

- `adact_scroll` → `adact_scroll_into_view`
- CLI `scroll` → `scroll-into-view`
- 動作は変わらない（ScrollItemPattern.ScrollIntoView）

#### 3b. 新 scroll コマンド

- `adact_scroll` MCP ツール + CLI `scroll` サブコマンド（新規）
- 対象: ScrollPattern を持つコンテナ要素
- パラメータ（3グループ排他、同グループ内で h+v 同時可）:

| グループ | パラメータ | 動作 |
|----------|------------|------|
| percent | `--percent-h N` / `--percent-v N` | SetScrollPercent。0〜100。片方のみ指定時、もう片方は NoScroll (-1) |
| small | `--small-h N` / `--small-v N` | SmallIncrement/Decrement × |N| 回。正=下/右、負=上/左 |
| large | `--large-h N` / `--large-v N` | LargeIncrement/Decrement × |N| 回。正=下/右、負=上/左 |

- 排他規則: percent / small / large は完全排他。同グループ内で h と v のみ同時指定可
- エラー: ScrollPattern を持たない要素に対して実行した場合はエラー

#### 3b 設計詳細

**Engine レイヤー:**

`IWindowSession` に追加:
```
Task ScrollAsync(string refId, ScrollMode mode, CancellationToken ct)
```

`ScrollMode` (abstract record, discriminated union 風):
```
abstract record ScrollMode;
record PercentMode(int? PercentH, int? PercentV) : ScrollMode;
record SmallMode(int? DeltaH, int? DeltaV) : ScrollMode;
record LargeMode(int? DeltaH, int? DeltaV) : ScrollMode;
```

`WindowSession.Toggle.cs` に実装を追加:
- ScrollPattern を取得
- モードに応じて SetScrollPercent / Scroll を呼び出し
- Small/Large の場合、|delta| 回ループし正負で Increment/Decrement を切り替え
- 片方が null の場合: percent → NoScroll(-1)、small/large → NoAmount

**MCP レイヤー:**

`WindowsTools.Toggle.cs`:
- 既存 `adact_scroll` → `adact_scroll_into_view` にリネーム
- 新 `adact_scroll`: ref + percentH/percentV/smallH/smallV/largeH/largeV (全て int?, 排他バリデーション)

**CLI レイヤー:**

`ToggleCommands.cs`:
- 既存 `ScrollIntoViewCommand.Build()` → name: "scroll-into-view"
- 新 `ScrollCommand`: ref + 6つの int? オプション

### 4. close-all 削除

- 削除対象: `adact_close_all` MCP ツール + CLI `close-all` サブコマンド
- 理由: 挙動が複雑。`close` で1つずつ閉じる運用とする
- 影響: breaking change
