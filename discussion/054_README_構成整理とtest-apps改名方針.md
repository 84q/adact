# 054: README / 構成整理 / `test-apps` 改名方針

## 背景

README とリポジトリ構成について、OSS 公開時に誤解を招きやすい点を整理する必要がある。

- README にライセンス案内が不足しており、`LICENSE` と整合した MIT 案内を明示したい
- ADACT と FlaUI / Playwright の関係を、初見ユーザーが短く理解できる補足が必要
- 役割が曖昧または現行運用と合っていないディレクトリが残っている
- `samples/` 配下の `SampleApp` は実態としてサンプル配布物ではなく、E2E / Smoke 用のテストアプリとして利用されている

調査時点で、`samples/SampleApp/` はソリューションおよびテストコードから参照されており、単純な名称変更ではなく参照更新を伴う対応が必要であることを確認済みとする。

---

## 決定事項

### 1. README 追記

- README に **MIT License** の案内を追加し、参照先として `LICENSE` を明記する
- README に **FlaUI を UIA 実装基盤としつつ、Playwright 的な snapshot / ref 体験を Windows デスクトップ操作へ持ち込むツール**である旨を 1 行程度で追記する

### 2. 不要ディレクトリ削除

- ルート直下の `spike/`、`research/`、`scripts/` は完全削除対象とする
- 削除後は、README・テスト・設定・その他文書に参照残りがないことを確認対象に含める

### 3. `samples/` の整理方針

- `samples/` は名称上「利用者向けサンプル集」に見えやすく、現状実態とズレるため整理対象とする
- ルート直下ディレクトリ `samples/` は `test-apps/` へ改名し、`samples/SampleApp/` は **`test-apps/SampleApp/`** となる方針とする
- この改名は見た目だけでなく、**テスト用アプリであることをリポジトリ構成上も明確化するための変更**として扱う

---

## 対象範囲

本合意を実装へ反映する際の対象は以下とする。

- `README.md`
- `LICENSE` 参照を伴う README のライセンス説明
- `samples/` から `test-apps/` への改名に伴うソリューション内プロジェクト参照更新（最終パス: `test-apps/SampleApp/`）
- テストコード内の `samples/` 参照パス更新
- 削除対象ディレクトリ（`spike/`, `research/`, `scripts/`）の実体削除
- 削除対象ディレクトリや旧 `samples/` 参照の残存確認

---

## 非対象範囲

- `discussion/` 配下の過去文書の修正
- `SampleApp` 自体の機能追加・仕様変更
- テストアーキテクチャや Layer 分類の見直し
- `docs/` 全体の包括的な再編
- `samples/` 以外のディレクトリ命名見直し

過去の `discussion/` 文書は履歴として保持し、本件では更新対象に含めない。
